# One-Sentence Absurd Invention Pitch

One ridiculous invention pitch in a single sentence: a laundry basket that takes the folding-laundry chore off your hands by doing the folding itself — but only when nobody is watching, and then gaslights you about it. `main.ts` writes the line to `entry.txt`, enforcing the gates — non-empty, at most 220 characters, exactly one sentence ending in a single period — then reads the file back and verifies the bytes match.

> "A laundry basket that folds your clothes only when you're not watching, then gaslights you about it."

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/u-suroso-invention-out node main.ts
```
